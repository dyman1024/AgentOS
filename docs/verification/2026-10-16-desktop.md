# 无付费桌面验收 · 2026-10-16

用户已确认最低要求为 macOS 26 + Apple Silicon，从空系统开始，暂不迁移旧 P0 数据；本轮先完成无付费验证，S3/S4/S6 真实模型评测暂缓。用户解锁后，使用 CUA 实际操作 Debug 宿主，读取辅助功能树并检查窗口截图。没有调用模型，没有连接真实邮件、日历或发布账户。

## 环境与方法

先检查默认数据目录的空启动台，再使用全新的临时数据目录。手写的“验收笔记”和“验收待办”通过真实 CLI 创建、写入源码、执行契约测试和激活；不是模型生成结果，也不预装到用户的空系统中。

准备命令：

```bash
make build
# 先退出已运行的 AgentOS。脚本启动临时会话并打印数据目录和 PID。
python3 scripts/prepare-desktop-fixtures.py
```

脚本还核验失败契约不能激活、失败后版本列表不变、契约测试不污染用户集合。它只负责准备数据，不自动点击桌面；以下交互由本次 CUA 实际操作验证。结束后用 ⌘Q 退出临时会话；临时目录保留供复查，再打开正常 App 时仍为空系统。

## 已通过的交互

| 路径 | 操作与观察 |
|---|---|
| 空系统 | 0 个应用、建议入口、对话输入区、事件状态正常；没有占位用户应用 |
| 设置与键盘 | 六个设置页可打开；⌘, 打开设置，Escape 返回；未配置服务明确显示未连接或禁用 |
| 空状态 | 通知显示“暂无通知”；修复后活动和应用授权页分别显示说明，不再是无解释的空列表 |
| 启动台与标签 | 中文应用搜索后仅显示匹配应用，清空后恢复；多标签切换与关闭、对话区收起和恢复正常 |
| 笔记→待办 | 先打开再关闭待办界面；通过笔记界面保存中文标题和正文。随后出现 task.created；重新打开待办可见对应标题，界面关闭期间核心仍处理事件 |
| 版本回滚 | 笔记 v2 保存数据后，从时间线回滚到 v1；页面标题变回 v1，已保存的中文标题和正文保留 |
| 活动撤销 | 撤销一条临时笔记写入后显示“已撤销”，并产生 data.restore 记录；其他笔记保留 |
| 活动详情 | 修复后实际点击展开，显示 before/after、changedFields、主体和修订；恢复记录的正文差异可核对 |
| 备份与恢复 | 在设置备份 notes，随后通过 CLI 修改正文。恢复预检弹出独立的宿主确认窗口；拒绝后 rev=2 和正文不变；重新预检并批准后恢复备份正文，生成 rev=3 和操作前备份 |
| 独立窗口 | 修复后，刚打开应用即分离也正常显示内容。填写尚未提交的标题，关闭独立窗口，再点“返回工作区”，输入仍保留 |
| 恢复模式 | 修复后点击“进入恢复模式”即关闭设置并显示恢复面板；“使用系统启动台继续”正常返回，并产生可见的恢复通知 |

本次通过粘贴或可访问性设值核对中文输入；不据此宣称覆盖所有输入法组合键。测试中最初的直接键入产生了不完整的临时记录，已通过活动撤销路径验证并撤回。

## 本轮发现并修复

| 问题 | 修复 |
|---|---|
| 活动详情无法通过正常点击展开 | 改为明确的展开/收起按钮，按展开状态读取真实审计详情 |
| 快速弹出应用后独立窗口白屏 | 先转移界面所有权，再挂载到独立容器；旧 SwiftUI 视图只有仍拥有实例时才能重新挂载 |
| 独立窗口状态误显示“正在生长”，缺少返回路径 | 区分独立窗口与构建状态，提供显示窗口、返回工作区；返回时复用同一 WebView，保留未提交输入 |
| 设置内进入恢复模式没有立即显示 | 同时关闭设置面板，再由宿主呈现恢复模式 |
| 空活动/授权页与图标按钮缺少说明 | 添加空状态与按钮的中文辅助功能名称 |

Debug 重建和 WebKit 沙箱回归通过；构建产物及随包的 aos、Bun 引擎、Claude 均核实为 arm64，最低系统元数据为 26.0。代码提交 `b63750e` 的[完整 CI](https://github.com/dyman1024/AgentOS/actions/runs/38841636258)通过，包含前后台交接、Release/sidecar 与免费评测预检；[日志摘录](2026-10-16-desktop-ci.txt)保留中文模型资源 skipped 和签名宿主 NOT RUN。运行时沙箱、CSP、桥接与授权规则没有放宽。

## 验收边界
