# AgentOS 重建版使用说明

当前是开发版本。本地确定性测试及[已列明的桌面路径](verification/2026-10-16-desktop.md)通过；真实模型评测按用户决定暂缓，真实账户、完整体验和正式分发尚未完成验收。阶段记录见 [重建方案](architecture/12-rebuild-plan.md)。

## 1. 启动与首次配置

从仓库运行 `make run`，或打开 `build/Build/Products/Debug/AgentOS.app`。要求 Apple Silicon、macOS 26 和开发工具链；新应用数据使用独立的 `AgentOS-Rebuild` 目录，不会自动迁入旧原型。

首次启动是空启动台。打开设置，选择 Anthropic 或 OpenRouter，填写模型 ID 和 Key。Key 存入 macOS 钥匙串；保存成功表示本机已保存，不代表在线验证成功。默认单次运行预算 3 美元；设置的预算是宿主与 SDK 的控制阈值，提供商最终账单可能略有差异。

## 2. 创建和操作应用

1. 在对话区选择 Builder，描述用途，例如“做一个支持标签、搜索和编辑的笔记应用，使用共享 notes”。
2. Builder 编写核心、界面、IDL、规格与契约测试。只有测试通过的版本才激活。
3. 点击启动台图标打开应用；使用标签切换。Operator 通过同一套应用接口操作，关闭界面不影响核心工具。
   应用可弹出为独立窗口；关闭独立窗口后，点工作区的“返回工作区”继续使用，未提交输入保留。
4. 若出现权限或出口确认，检查可信宿主窗口中的动作、参数和来源再决定。拒绝会结束相应操作。
5. 对失败结果看活动详情，区分确定失败和 unknown；unknown 表示外部结果不确定，系统不会盲目重试。

应用间联动需要可调用的工具和数据事件。可让 Agent 将“笔记更新后提取 TODO 并写入待办”保存为固定自动化。固定计划只执行已批准的工具序列；工具契约或权限发生变化会暂停，重新检查后才恢复。

## 3. 撤销、回滚与恢复

| 操作 | 作用与限制 |
|---|---|
| 活动 → 详情 | 查看运行、原因、参数、结果与数据字段变化 |
| 活动 → 撤销 | 数据/文件按历史与当前版本核对；冲突返回，不覆盖后续修改；日历创建可做受限补偿 |
| 应用版本 → 回滚 | 恢复代码与接口，保留共享数据和应用私有存档 |
| 设置 → 数据 → 备份与恢复集合 | 预览集合差异，从备份或时间点恢复；确认前后有写入则预览失效 |
| 恢复模式 | 停止生成桌面和自动化，导出数据、回滚应用、返回系统启动台 |

按住 Option 启动或设置 `AGENTOS_SAFE_MODE=1` 可进入恢复模式。连续两次未正常退出也会进入恢复模式。新数据恢复创建新修订，保留审计；邮件发送、远端发布等不可逆结果无法靠本地撤销消除。

## 4. 连接服务

| 服务 | 设置方式 | 当前边界 |
|---|---|---|
| 文件 | 系统服务 → 授权文件夹 | 应用还需申请文件夹能力；逐次检查，撤销立即生效 |
| 搜索/发布 | 填写 Brave 或 GitHub 凭据 | GitHub 提交被接受不等于 Pages 已部署 |
| 邮件 | 邮箱、IMAP TLS 993、SMTP TLS 465、应用专用密码 | 定时只读同步；读取不标已读；发送受出口策略约束 |
| 日历/通讯录 | 点击系统授权按钮 | 由 macOS 授权决定可用性；日历创建不发送参会邀请 |
| MCP | 短名、HTTPS 地址、可选 Token | HTTP 驱动；每次调用重查 schema/连接/授权，不接受反向 sampling |
| 媒体 | 授权媒体文件夹，再让 Agent 索引与播放 | 大文件通过受控范围读取；真实播放体验仍待实机验收 |
| 工作间 | 安装发行者签名镜像，或开发者选择本地镜像 | 无网卡和默认共享；镜像说明见 [VM](../vm/README.md) |

不要把 Key 写进应用源码、聊天或公开 issue。断开账户和撤销应用权限是不同操作；设置中分别提供入口。

## 5. 后台与桌面

关闭主窗口时 App 仍运行。只有在设置中明确启用“登录后后台运行”，才注册系统登录项；App 完全退出后由后台宿主接管。前后台不会同时写同一个内核。后台遇到需要确认的动作会暂停并留下通知。

设置中的桌面选项可将已通过测试的 Web 应用设为桌面。它能列出/打开应用和读取摘要；系统确认、设置与恢复仍由宿主绘制。桌面失效或健康检查超时会回到系统启动台。

## 6. 数据、包与 CLI

数据根：`~/Library/Application Support/AgentOS-Rebuild/`。`apps/` 保存源码与版本；`system/` 保存数据库、会话、备份和 VM。不要手工移动正在运行的数据库。

数据导出是带 schema 和标签的 JSON，不含媒体原文件。导入遇到 ID/schema 冲突整批失败，保留现有数据。签名应用包导入会分配新身份、重新申请权限并测试，不继承作者授权。

App 运行后，可使用内置 CLI：

```bash
build/Build/Products/Debug/AgentOS.app/Contents/Resources/engine/aos apps list
build/Build/Products/Debug/AgentOS.app/Contents/Resources/engine/aos data query notes --text 周会
build/Build/Products/Debug/AgentOS.app/Contents/Resources/engine/aos call notes.list '{}'
```

第三条的命名空间以实际应用为准。`--dry-run` 只检查和描述，不执行；需要用户确认的 CLI 调用返回 `needs_confirmation`，不会绕过宿主 UI。

## 7. 已知限制

完整 VM 内存恢复在当前机器失败；显式冷磁盘恢复已通过。WASM 仅 core module v1；原生使用固定 swiftc；自动化仅固定工具序列。独立 `.app`/HTML 分享、联合 schema 迁移、按应用/运行的批量时间点恢复尚未实现。付费评测、账户接入、桌面验收与正式发行条件见 [验收记录](verification/2026-10-16-rebuild.md)。
