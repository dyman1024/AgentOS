01

理念 / Principles

不是应用商店，是一片会生长的土壤。

AgentOS 把「装应用」变成「长应用」。三条原则决定了它的每一个交互：应用从对话里诞生，生来就彼此连通，而你的 Agent 拥有照料它们的全部权力。

  1. 01生成 · 验证 · 修复

    应用是生成的

    没有预装软件。你说出需要，Agent 写出它、跑起来、自己测一遍，再交到你手上。不满意？接着说。

  2. 02MCP · 事件总线

    协议天生互联

    每个应用诞生时就带着接口和事件。笔记里写下 TODO，待办自动出现；邮件一到，日历已经排好。

  3. 03可回滚 · 可审计

    Agent 是主人

    它拥有这台电脑的最高权限：主动订阅、跨应用调用、随时动手。可撤销的事直接做，不可逆的事先问你。

    系统剖面 / Anatomy

    体验像 Parallels，实现像 WSL2。

    你看到的是一台完整、独立的电脑；底下是六层分工。界面全部由 Mac 原生渲染，跑得快、输入法和窗口都是原生的；编译、后台服务和不可信代码，交给一台你看不见的 Linux 工作间。
